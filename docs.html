Welcome to the GraphViz Scripting API. You can write standard Python code to implement graph algorithms (like BFS, DFS, Dijkstra) and use the built-in functions below to interact with the canvas and animate your algorithm step-by-step.

Graph Information

Use these functions to read the structure and weights of the graph drawn on the canvas.

def neighbors(node)
Read

Returns the neighbors of the specified node.

ParameterTypeDescription
nodeint | strThe ID of the target node.

Returns: A dictionary (or iterable) of the node's neighbors.

def weight(node_a, node_b)
Read

Returns the weight of the edge between node_a and node_b.

ParameterTypeDescription
node_aint | strThe starting node.
node_bint | strThe ending node.

Returns: A numeric value representing the weight. Returns float('inf') if no edge exists.

Animation Controls

Use these functions to create visual steps in your animation player. Every call to these functions creates a new "Step" in the timeline.

def select(node)
Animation

Highlights a node to show it is currently selected (usually the node currently being processed in a loop).

def visit(node, msg=None)
Animation

Marks a node as visited. Visited nodes generally keep a specific color state to show they have already been processed.

ParameterTypeDescription
msgstr (optional)A message to display in the log console during this step.
def color_node(node, color)
Animation

Forces a specific color onto a node.

ParameterTypeDescription
colorstrA valid CSS color (e.g., "red", "#3498db").
def color_edge(u, v, color)
Animation

Colors the edge connecting node u and node v.

ParameterTypeDescription
colorstrA valid CSS color (e.g., "blue", "#2ecc71").
def draw_path(path, color="#e74c3c")
Animation

Draws a thick highlighted path connecting a sequence of nodes.

ParameterTypeDescription
pathlistA list of node IDs representing the path (e.g., [1, 2, 5, 8]).
colorstr (optional)The color of the path. Defaults to red.

Example: BFS Algorithm

Here is an example of how to combine standard Python code with the Graph API to visualize a Breadth-First Search.

def bfs(start_node):
    queue = [start_node]
    visited = set([start_node])
    
    # Visual: Mark the start node
    visit(start_node, f"Starting BFS at node {start_node}")
    
    while queue:
        current = queue.pop(0)
        select(current) # Visual: currently processing
        
        for neighbor in neighbors(current):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
                
                # Visual: animate the traversal
                color_edge(current, neighbor, "#f1c40f")
                visit(neighbor, f"Discovered node {neighbor}")

# Start the algorithm (assuming node '1' exists in your graph)
bfs('1')
